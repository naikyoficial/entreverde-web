# Videos — Entre Verde

Colocar los videos en esta carpeta con los siguientes nombres exactos:

| Archivo | Sección | Descripción |
|---|---|---|
| `sustrato.mp4` | El Sustrato | Video en loop (sin audio) del sustrato — close-up, textura, mezcla cayendo, etc. |

**Formato recomendado:** MP4 (códec H.264), sin audio, loop corto (5–15 segundos), resolución 1080p o menor para que pese poco.

**Importante — peso del archivo:** GitHub permite subir archivos de hasta 25MB desde la interfaz web (arrastrando el archivo). Si el video pesa más que eso, hay que comprimirlo antes de subirlo (por ejemplo con HandBrake, o exportándolo en menor calidad/resolución desde el editor de video).
